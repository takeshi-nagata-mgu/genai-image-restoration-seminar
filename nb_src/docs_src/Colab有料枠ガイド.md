# Google Colab の無料枠・有料枠 ガイド（誤解しやすいポイント集）

> 2026年10月時点の情報です。Colab の料金・GPU の種類・消費レートは予告なく変わります。
> **必ず最新の公式ページ（https://colab.research.google.com/signup ）と、実行中のリソース表示で確認してください。**

---

## 1. まず押さえる3つのこと

1. **Colab の GPU は「借り物の一時的なPC（ランタイム）」です。**
   接続が切れると、そのPCは**丸ごと消えます**。インストールしたライブラリ、ダウンロードしたモデル、生成した画像も消えます。
   → 結果は **Google Drive に保存** するか、**こまめにダウンロード** してください。
2. **無料枠は「保証なし」です。**
   GPU が割り当てられない、途中で切断される、利用上限に達して数時間〜1日 GPU が使えなくなる、ということが普通に起こります。上限値は非公開で変動します。
3. **有料枠は「使い放題」ではありません。「コンピューティングユニット（CU）」というプリペイド残高制です。**
   GPU に接続している間、時間に比例して CU が減ります。残高が 0 になると無料枠と同じ扱いに戻ります。

---

## 2. プランの種類（目安）

| プラン | 料金の目安 | 含まれる CU | 主な特徴 |
|---|---|---|---|
| 無料 | 0円 | なし | T4 GPU（空いていれば）。最長12時間・保証なし |
| Pay As You Go（従量課金） | 100 CU 約1,200円（$9.99） | 購入分のみ | **月額なし。必要なときだけ買う。セミナー後の試用にはこれが最適** |
| Colab Pro | 月額 約1,200円（$9.99） | 毎月 100 CU | 高メモリ・高性能GPUを選択可、ターミナル |
| Colab Pro+ | 月額 約6,000円（$49.99） | 毎月 500〜600 CU | Pro の機能 + **バックグラウンド実行**、最長24時間 |

- 価格は為替・税・時期により変わります。Google One の「Google AI」プランに Colab の CU が含まれる場合もあります。
- **購入した CU には有効期限があります（購入から90日）。** 月額プランの CU も使い切らないと失効します。
- **サブスクリプションは自動更新です。** 使わなくなったら必ず解約してください（Google Pay の定期購入から）。

## 3. GPU ごとの CU 消費量（目安）

| GPU（ランタイムのタイプ） | GPU メモリ | 消費の目安 | 1時間あたりの費用目安 | 本セミナーでの用途 |
|---|---|---|---|---|
| T4 | 15 GB | 約 1.2〜2 CU/時 | 約15〜25円 | ノートブック 00〜09、12〜14（無料枠でも可） |
| L4 | 22.5 GB | 約 1.7〜5 CU/時 | 約20〜60円 | LoRA 学習、VLM、SUPIR（工夫すれば） |
| A100 40GB/80GB | 40/80 GB | 約 5〜15 CU/時 | 約60〜180円 | SUPIR・FLUX 系の大型モデル |
| G4（RTX PRO 6000） / H100 | 96 / 80 GB | 約 9 CU/時〜 | 約100円〜 | 最大級のモデル |

- 消費量は **Google が公表しておらず変動します**。接続中に右上の「リソース」パネル（RAM/ディスク表示をクリック）で **現在の消費レート（CU/時）と残高** が確認できます。**有料GPUを使う前に必ず確認してください。**
- **CU は「計算している時間」ではなく「GPU ランタイムに接続している時間」で減ります。** コードを実行していなくても、接続したまま放置すると減り続けます。

## 4. 時間制限について（最も誤解が多いところ）

| 項目 | 無料 | Pro / Pay As You Go | Pro+ |
|---|---|---|---|
| 1セッションの最長時間 | 最長12時間（実際はもっと短いことが多い） | 最長24時間（CU残高がある限り） | 最長24時間 |
| アイドル（無操作）での切断 | あり（目安90分程度） | あり | あり |
| ブラウザを閉じたら？ | しばらくして切断 | しばらくして切断 | **バックグラウンド実行**なら継続 |

誤解しやすい点：
- **「有料にすれば24時間動き続ける」わけではありません。** 24時間は上限であり、保証ではありません。CU が尽きれば止まります。
- **「アイドル」とは「コードが何も実行されていない状態で、画面操作もない状態」です。** 長い学習を実行中なら、通常はアイドル扱いにはなりません。ただし **ブラウザのタブを閉じる・PCがスリープする** と、Pro+ のバックグラウンド実行以外では切断されることがあります。
- **切断されたら、ランタイムの中身はすべて消えます。** 長い処理は途中経過（チェックポイント）を Google Drive に保存する作りにしてください。
- 「ランタイムを再起動」は Python を再起動するだけでファイルは残りますが、「ランタイムを接続解除して削除」はPCごと返却します。

## 5. 失敗しないための手順

1. 配布ノートブックを開いたら **［ファイル］→［ドライブにコピーを保存］**（自分のコピーで作業）
2. **［ランタイム］→［ランタイムのタイプを変更］** で GPU を選ぶ
   - 無料：T4 GPU
   - 有料：L4 / A100 など。大型モデルは **「ハイメモリ」もオン**（システムRAM 50GB 前後）
3. 一番上のセットアップセルから順に実行（▶ または Ctrl+Enter）
4. 結果を保存：
   ```python
   from google.colab import drive
   drive.mount('/content/drive')          # Google Drive をマウント
   img.save('/content/drive/MyDrive/result.png')
   ```
5. **終わったら必ず ［ランタイム］→［ランタイムを接続解除して削除］**
   （有料枠ではこれをしないと CU が減り続けます）

## 6. 社外秘データに関する注意

- Colab は Google のクラウド上で実行されます。社外秘の画像・図面・製品データをアップロードする前に、**社内の情報セキュリティ規程を確認** してください。
- 社外に出せないデータは、**ローカルの GPU PC**（`docs/ローカル環境構築ガイド.pdf`）で同じノートブックを実行できます。
- 企業向けには Colab Enterprise（Google Cloud 上、データの所在や権限を管理可能）という選択肢もあります。
